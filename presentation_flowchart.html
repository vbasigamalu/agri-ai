Agri-AI : 7-Stage Defensive Visual AI Pipeline Computer Vision Architecture

Solving Out-Of-Distribution Clutter, Variable Lighting, and Overconfidence in Real Farms
SIH-2024 / Vision Engine
01

🔍 Image Quality Check

Detects poor lighting, motion blur, and out-of-focus captures before invoking heavy models.

Laplacian variance blur detector (> 100)
Over/underexposure brightness histogram
Rejects non-plant images (green ratio check)
02

🍃 Leaf Saliency & Contour

Isolates plant foliage from human hands, soil, fences, and background artifacts.

HSV color thresholding & masking
Morphological contour segmentation
Calculates primary leaf bounding boxes
03

🌿 Multi-Leaf Aggregator

Handles real farm canopy images containing multiple leaves with varying infection levels.

Separates candidate leaves (N ≥ 1)
Per-leaf independent inference run
Healthy vs. Infected ratio calculation
04

✂️ Background Suppressor

Removes background bias so model learns disease pathology, not soil or farm textures.

Tensors cropped to bounding region
Resizes cleanly to 224 × 224 px
CHW planar tensor normalization [0, 1]
05

🚀 Dual-Engine Inference

High-throughput edge & server execution with cross-platform fallback resilience.

Primary: PyTorch ONNX Runtime Session
Fallback: TensorFlow.js WebAssembly (WASM)
Zero native C++ build dependencies needed
06

🛡️ OOD Uncertainty Gate

Blocks overconfident hallucinations on unknown weeds, hands, or unseen diseases.

Shannon entropy on probability distribution
Top-1 vs. Top-2 margin comparison (> 0.20)
Marks ambiguous cases for human review
07

🔬 Severity & Grad-CAM

Quantifies disease progression and generates visual explainability for agronomists.

Lesion area percentage computation
Grades: Mild (<10%), Moderate, Severe (>35%)
Grad-CAM heatmap of diagnostic focus
08

📋 Actionable Prescription

Couples technical disease detection with field-ready agronomic treatments.

Biological IPM treatments (Neem, Trichoderma)
Exact chemical active ingredient & dosage
Weather-linked spray advisory checklist
🛡️ Zero Hallucinations Policy: Quality checks + Uncertainty Gates prevent wrong chemical purchases
FPR on Non-Crops: < 0.5%
Inference Latency: < 180ms
